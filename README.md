# About-blank Opener (A:BO/ABO)

This is my dream website. I could never really find a good one while in school—so I finally made one! My games site utilizes `about:blank` to display sites with iframes. I chose this method because `about:blank` is a site essential to any browser. It is most commonly used for redirects, but if a school were to block it...it would ruin the chromebooks.

*Sites you visit on here are not tracked by your browser history, they are either ignored or simply listed as an about:blank page. Browsers do keep track of cookies, so it is *not* fully untracked
> [!IMPORTANT]
> If you want to know how to set up or unblock this website on your school Chromebook, please check out the dedicated guide: [How-to-unblock.md](How-to-unblock.md)
